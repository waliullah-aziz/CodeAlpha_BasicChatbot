# CodeAlpha — Basic Chatbot

A simple chatbot written in Python, built for my CodeAlpha Python Programming internship (Task: Basic Chatbot).

## What it does

The chatbot talks with you in the terminal:

- You say **hello** → it greets you back
- You ask **how are you** → it answers
- You ask **your name** → it tells you its name
- You say anything it does not know → it honestly says *"Sorry, I don't understand."*
- You say **bye** → it says goodbye and the chat ends

## How it works

The program listens to what you type, checks your words against a small list of answers using `if / elif / else`, and prints the matching answer. It keeps going in a `while` loop until you say **bye**.

## How to run it

```
python chatbot.py
```
